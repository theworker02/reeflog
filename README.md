# reeflog

Reef CSV/TSV log tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/reeflog/

## Install / run

```bash
git clone https://github.com/theworker02/reeflog.git
cd reeflog
node src/cli.js
node --test
```
